# Bach Viet Cam Backend

Node.js and Express backend organized by domain modules.

## Development

```bash
npm run dev
```

The API runs at `http://localhost:3000` by default.

Health check: `GET /api/health`

## Modules

- `auth`
- `classes`
- `community`
- `ensemble`
- `music-library`
- `platform`

Each module lives under `src/modules/` and is currently an empty scaffold for feature implementation.
